# Calculation Rules

Use these rules in order for any teaching unit, not just marking-heavy courses.

## 1. Prefer course-owner estimates

If the course lead or department has already given an hours budget, use that first.

Common forms:

- `15h for the whole assessed sheet`
- `10h for formative PS2`
- `Q3 is about 9h, Q1+Q2 about 6h`

Treat these as the strongest budgeting evidence unless later emails clearly narrow the workload.

## 2. Generic fallback formula

When no better estimate exists, use:

`sheet time = setup time + marking time + marks entry/checking time`

Typical fallback:

- `setup time = 1h`
- `marking time = number of submissions x 5min`
- `marks entry/checking time = 0.5h`

State clearly that this is a rule of thumb.

## 3. Problem classes / support sessions

Default formula:

`session time = class duration + prep time`

Use `1h class + 1h prep = 2h` per session unless the email evidence supports a different number.

Prep time can include:

- reading the worksheet
- reading solutions
- travel within campus / getting to the room
- brief setup or debrief

## 4. Other taught or supported sessions

Use the same structure for tutorials, labs, workshops, floorwalking, seminar support, or other student-facing sessions:

`session time = scheduled session length + prep time`

Guidelines:

- use the actual scheduled duration when known
- use `0.5h to 1.5h` prep depending on the evidence
- keep recurring sessions itemized by date if the user needs a detailed breakdown

## 5. Meetings, training, and onboarding

Default formula:

`activity time = actual duration`

Add separate prep or follow-up only when the evidence supports it.

Examples:

- staff meetings
- onboarding or induction
- required training
- watching a meeting recording
- preparatory briefing meetings

## 6. Partial marking by script range

If the full assessed or formative sheet has a total-hours allocation and the user marked only a subset of scripts, use:

`user time = full-sheet allocation x (scripts handled / total scripts)`

Example:

`15h x (51 / 151) = 5.1h`

Round modestly upward only when consistency checking or course-site admin clearly adds a little extra.

## 7. Partial marking by question

If the course lead explicitly split the workload by question, use the explicit split first.

If no explicit split exists, estimate from:

- number of questions handled
- relative difficulty or weight of the question
- whether the user also did final mark entry or temporary scores

Do not blindly divide by the number of questions if one question is clearly heavier.

## 8. Course-site / marks-entry admin

Keep marks-entry admin inside the relevant task when it belongs to that task:

- final mark entry for one formative sheet
- temporary score entry for one question split
- course-site checking tied to one batch

Add a separate miscellaneous admin line only for leftover coordination that is not already captured.

Typical miscellaneous admin allowance:

- `0.5h to 1h`

Examples:

- email coordination
- checking allocations or materials
- course-site follow-up across tasks

## 9. Rounding

- Prefer half-hour steps when the arithmetic lands there naturally.
- If the user needs one clean integer, choose the nearest defensible whole number.
- When in doubt, offer:
  - exact estimate
  - rounded claim number

## 10. Explain assumptions

When sharing the result with the user or a colleague, separate:

- email-confirmed facts
- formulas used
- small assumptions used for rounding or prep/admin
